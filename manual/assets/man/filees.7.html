NAME

filees — OpenBSD file-synchronisation server: accounts, layout and tools

DESCRIPTION

filees is a file-centric synchronisation system. The desktop client keeps local folders in sync with Subversion repositories. The server target is OpenBSD. There is no resident FileES daemon and no FileES listener. The system sshd(8) is the only privileged network endpoint. Public Shares, when enabled, are served by the host httpd(8) through FastCGI.

SVN is transport and storage. Revision-control semantics are secondary. On-disk files, atomic rename and short-lived forced commands are the operational contract.

ACCOUNTS

_filees-state
Owns /var/filees and most of /etc/filees. Administrative commands run as this user.
_filees-onboard
Public bootstrap account. Forced command filees-bootstrap-entry(8).
_filees-tunnel
OTP account with one reverse tunnel. Forced command filees-entry(8).
_filees-client
Installation-key account for the service repository and control plane.
_filees-data
Installation-key account for data-repository svnserve -t. This is the user in the canonical repository URL.
_filees-mobile
Mobile protocol: read a share, write under mobile-uploads/.
_filees-recovery
Capability-bound archive download after realm removal.
_filees-links
Public FastCGI process. Owns the public cache. Has no SVN credentials.
_filees-access
Group for set-id client, mobile and ownership-corrector binaries.
_filees-public
Group for the authority socket shared with links.

LAYOUT

/etc/filees/server.json
Server toolchain configuration. See filees.conf(5).
/etc/filees/public-links.json
Public FastCGI configuration. See filees-public-links(5).
/etc/filees/install.conf
Signed updater configuration. See filees-install(8).
/var/filees/onboarding
Tickets, operation bundles and audit files.
/var/filees/activation
Generated authorized_keys, authz, records and proofs.
/var/filees/service-repo, /var/filees/service-wc
Canonical service repository and its working copy.
/var/filees/repositories
FSFS data repositories, one directory per repository UUID.
/var/filees/repository-operations
Durable worker results, deletion archives and Public Shares state.

TOOLS

Operator commands live in /usr/local/sbin: filees-admin(8), filees-operation(8), filees-install(8) and filees-rotate(8).

Forced commands and short-lived workers live in /usr/local/libexec/filees. The OpenBSD integration script assigns set-id owners and modes. The generic install-server.sh writes ordinary modes and is not a complete upgrade on an already integrated host.
