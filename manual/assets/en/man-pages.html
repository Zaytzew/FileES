OpenBSD manual pages

The server toolchain ships mandoc sources written in the same style as the rest of the operator documentation: one page per command or configuration file, filesystem paths as the contract, explicit non-goals, and .Xr cross-references. They are not a second product story. The HTML chapters explain why; the man pages tell an operator what to type.

Style

Sources live in docs/man/man5, docs/man/man7 and docs/man/man8. They use mdoc macros (.Dd, .Dt, .Nm, .Nd, .Sh, .Xr). English is canonical, matching this HTML manual and the binaries' diagnostic text. Section 8 is used for every server command, including forced-command dispatchers, because none of them is a general user utility.

mandoc -T lint docs/man/man8/filees-admin.8
man -l docs/man/man7/filees.7

Installation

packaging/build-server.sh copies the pages into the bundle as share/man/manN/. install-server.sh installs them under $PREFIX/man (default /usr/local/man). They are not currently a FILEES-BIN payload; signed filees-install still manages the 16 binaries only. After a bootstrap:

man filees
man 5 filees.conf
man 8 filees-admin
