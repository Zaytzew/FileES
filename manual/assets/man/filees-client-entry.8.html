NAME

filees-client-entry — FileES per-key dispatcher for svnserve, control and Whale sessions

SYNOPSIS

filees-client-entry

DESCRIPTION

filees-client-entry is the set-id dispatcher installed for installation-key sessions. sshd(8) selects the account (_filees-client) or _filees-data and the per-key command= line. filees-client-entry accepts exactly three original commands:

svnserve -t
Tunnel-mode Subversion.
filees control-v1
One authenticated control-plane ticket, then filees-worker(8).
filees whale-v1
One framed Whale request. The dispatcher claims the same activation session lease used for Subversion, starts a gated worker in a separate process group and relays only private pipes. Revocation closes the input and terminates the complete worker process group, including a running svnmucc.

Before a control-plane ticket or Whale request it runs filees-service-wc-corrector(8) so a previous root-owned administrative svn cannot leave the service working copy unreadable to _filees-state.

The client identity is taken only from the forced per-key command line. It is never accepted from the Whale frame. The Whale worker authorizes the logical repository against the current client projection and stores transport state outside every working copy.

The image is _filees-state: _filees-access mode 4550. It is not a general shell.

SEE ALSO

filees-service-wc-corrector(8), filees-serving-state(8), filees-worker(8)
