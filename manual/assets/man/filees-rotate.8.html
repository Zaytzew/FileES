NAME

filees-rotate — perform an explicit SVN FSFS generation change

SYNOPSIS

filees-rotate -repo path -archive directory [-size threshold] [-age-days n] [-dry-run] [-force] [-break-locks] [-dump-depth n]

DESCRIPTION

filees-rotate replaces a hot repository with a new generation. The new generation has a new UUID and starts at revision 1 equal to a complete dump of the old HEAD, including versioned properties such as svn:needs-lock. It inherits conf/ and hooks/, is verified with svnadmin verify and a tree comparison, then swapped atomically. The old generation becomes a frozen, commit-blocked FSFS archive. Existing working copies do not survive the UUID change.

For the FileES append-only profile, rotation is a retention tool, not a performance tool. There is no built-in scheduler. Running filees-rotate is an operational decision. The same staging and swap machinery is reused by LOAD_REPOSITORY_DUMP.

Prefer filees-admin(8) repo rotate. It performs the same rotation under the per-command pledge(2) and unveil(2) profile that every other administrative operation gets, and takes its paths from the server configuration instead of the command line, so it cannot address a repository outside the configured tree. filees-rotate applies no sandbox at all: it is the one server executable that runs as root with no profile and takes absolute paths from argv, which is also why it can break live locks. Sandboxing filees-rotate itself is not implemented yet; until then it is the manual escape hatch for a repository the configured path cannot reach, not the ordinary way to rotate.

OPTIONS

-repo path
Absolute path of the hot repository.
-archive directory
Archive directory on the same filesystem as the repository, so the swap is a rename.
-size threshold
Rotate when packed size reaches this. Default 25GiB.
-age-days n
Rotate when revision 1 is older than n days. Default 365.
-dry-run
Print the decision without rotating.
-force
Rotate regardless of triggers.
-break-locks
Proceed despite active locks. This destroys live edit passports.
-dump-depth n
Also archive a gzip dump of the last n revisions before HEAD. Zero, the default, writes no extra dump. The frozen FSFS archive is canonical.

EXIT STATUS

The filees-rotate utility exits 0 on success, and >0 if an error occurs.

EXAMPLES

$ filees-rotate -repo /STORAGE01/filees-repos/UUID \
    -archive /STORAGE01/filees-archive -dry-run
