NAME

filees-ssh-auth — BSD Authentication style for the FileES OTP tunnel

SYNOPSIS

filees-ssh-auth

DESCRIPTION

filees-ssh-auth is installed as /usr/libexec/auth/login_-filees with owner _filees-state, group auth and mode 4550. sshd(8) invokes it for _filees-tunnel keyboard-interactive authentication.

The OTP is received on file descriptor 3, not from the environment. A successful comparison advances the operation bundle from awaiting_tunnel to tunnel_authorized. filees-entry(8) then claims that state.

The _filees-tunnel password field must not be ‘*’; BSD Auth rejects such accounts before a local style can run. The OpenBSD installer writes an unknowable random hash.
