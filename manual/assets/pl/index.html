FileES / publiczny podręcznik

Podręcznik FileES: User i Tech

FileES synchronizuje katalogi ze zdalnym repozytorium i pozwala udostępnić pliki osobie, która nigdy nie zainstaluje klienta. Ten zestaw stron HTML jest publicznym podręcznikiem systemu, podzielonym na dwa działy: User opisuje codzienną obsługę — co kliknąć i po co, Tech opisuje architekturę i kontrakty systemu. Administracja korzysta przede wszystkim z części User. Strony podręcznika OpenBSD (mandoc) należą do części Tech.

Jak czytać ten podręcznik

Host już serwuje te strony. Treść jest rozdzielona: strony User to instrukcje obsługi, a Tech Eksploatacja zawiera szczegóły, które wcześniej sąsiadowały z nimi na tych samych stronach. Stare adresy rozdziałów zostają, żeby nie zepsuć linków ani allowlisty.

User Instrukcja i howto

Co system robi i po co. Pulpit, udziały, zapraszanie ludzi, odzyskiwanie danych.

 Tech Architektura i kontrakty

Protokoły, przepływ ticketów, pledge/unveil, wymagania, mandoc.

Dawny pojedynczy manual-filees.html pozostaje wyłącznie przekierowaniem. Każda strona trzyma system wizualny filees:space i nie ma zależności sieciowych. FileES jest wersją roboczą. Znacznik dojrzałości nie jest wydaniem produktu.

User

Tu zaczynasz jako użytkownik pulpitu albo administrator strefy. Ton: co kliknąć, co się wtedy dzieje, po co dana funkcja istnieje. Techniczne nazwy protokołu zostają po angielsku; pulpit mówi potocznym językiem (strefa to realm).

  • Howto pulpitu — instalacja klienta, pierwszy folder, Ustawienia, blokady, Dziennik.
  • Klient Android — parowanie QR, przegląd udziałów, wysyłanie plików do mobile-uploads/.
  • Udziały publiczne — udostępnij pliki komuś, kto nigdy nie zainstaluje FileES.
  • Administracja — zaproszenie, cofnięcie, odzyskanie, rotacja repozytorium.

Tech

Tu zaczynasz, jeśli implementujesz, audytujesz albo wdrażasz. Ton: kontrakty, odrzucone alternatywy i to, co musi zostać prawdą.

  • Architektura — topologia, sztafeta ticketów, OTP, skok SSH, sandbox.
  • Instalacja serwera — install-server.sh, install-ssh.sh, filees-install.
  • Eksploatacja — pliki ticketów, schematy poczty i audytu, protokół rotacji i usunięcia strefy, object_map, sshd i server.json.
  • Dodatek bezpieczeństwa — niezmienniki, transport, granica GUI.
  • Strony man / wyciąg CLI — rola, wywołanie, flagi i przykłady każdego polecenia serwera.
