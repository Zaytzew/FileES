This is the FileES demo server. You activate it with the Demo button in a FileES client that is not yet connected to any server — no invitation needed, just an e-mail address.

Jak zacząćHow to start

Zainstaluj FileES

Install FileES

Pobierz klienta dla Windows (MSI) albo Linuksa (AppImage) ze strony filees.space.

Download the client for Windows (MSI) or Linux (AppImage) from filees.space.

Kliknij „Demo”

Click “Demo”

W kliencie, który nie jest jeszcze aktywowany, wybierz Demo i podaj swój adres e-mail.

In a client that is not yet activated, choose Demo and enter your e-mail address.

Wpisz kod z wiadomości

Type the code from the e-mail

Po chwili klient jest połączony z tym serwerem. Dodaj folder i pracuj jak z własnym serwerem.

A moment later the client is connected to this server. Add a folder and work as you would with your own server.

Działa jak na własnym serwerze

Works as on your own server

  • synchronizacja folderów, z postępem pierwszej publikacji
  • Pliki w czasie — stan z dowolnej chwili i odzyskiwanie wersji
  • blokady plików i ich zwalnianie
  • dziennik zdarzeń i wydania z komentarzem
  • folder sync, with progress for the first publication
  • Files in time — any moment of history, earlier versions restored
  • file locks and their release
  • journal of events and releases with a comment

Ograniczenia demo

Demo limits

  • konto działa 120 minut i ma 1 GB miejsca
  • jedna aktywacja demo na instalację
  • linki publiczne i półki można obejrzeć, ale nie przesyłają plików
  • granty dla innych stref i parowanie telefonu są wyłączone
  • the account lasts 120 minutes with 1 GB of space
  • one demo activation per installation
  • public links and shelves can be viewed but transfer no files
  • grants to other realms and phone pairing are disabled

Twoje daneYour data

Po 120 minutach serwer usuwa konto demo razem z plikami. Zapis samej aktywacji znika po 14 dniach. FileES nie wysyła telemetrii, a ta strona nie ładuje nic z zewnątrz. Szczegóły: polityka prywatności.

After 120 minutes the server removes the demo account together with its files. The record of the activation itself is deleted after 14 days. FileES sends no telemetry, and this page loads nothing from elsewhere. Details: privacy policy.
