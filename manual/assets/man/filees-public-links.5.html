NAME

filees-public-links — FileES public FastCGI configuration (/etc/filees/public-links.json)

DESCRIPTION

filees-links(8) reads this file. It does not read filees.conf(5) and must not be given SVN credentials. The schema name is filees.public-links/v1.

KEYS

fastcgi.network, fastcgi.address
Listener for httpd(8). The shipped value is a Unix socket /var/www/run/filees/filees-links.sock owned _filees-links: www mode 0660.
backchannel.network, backchannel.address
How links asks filees-public-authority(8) for a leaf. On a shared host this is the Unix socket /var/run/filees/public-authority.sock. A split topology uses a server-established reverse SSH forward with Unix sockets at both ends. Raw TCP, including loopback, is rejected; migrate before upgrading. The socket directory must already exist, owned by its service account or root, with no access for others and no group write permission. Use mode 0700 for one account, or 0750 with the dedicated socket group. The directory ancestry is checked before the sandbox is applied; the socket type, owner and permissions are checked on each new connection. The socket may be absent at startup while the authority or tunnel starts.
visit_key_file
HMAC key for signed visit URLs, mode 0600.
cache.root, cache.ttl, cache.max_size
Independently configurable absolute private cache directory, mode 0700, owned by _filees-links. The example uses /var/filees-downloads/cache. Keep the directory on persistent storage outside system temporary cleanup; exclude its contents from backups. TTL cannot exceed 24 hours. The shipped values are 12 hours and 10 GiB.
bundle.max_files, bundle.max_size
Hard limits for ZIP requests. ZIP output is streamed, but all selected leaves first occupy cache space. Logical limits do not replace filesystem capacity checks.
intake_root, max_upload_size
Closed upload-shelf quarantine. Must match upload.intake_root in filees.conf(5). Job subdirectories are mode 0770 so _filees-state can reap them.

FILES

/etc/filees/public-links.json
Installed configuration.
/etc/examples/filees-public-links.httpd.conf
Ordered httpd(8) locations to merge into the existing HTTPS origin.
